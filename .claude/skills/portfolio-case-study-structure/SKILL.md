name: portfolio-case-study-structure
description: Use when writing case studies: center on a 'knot' for focus.
category: portfolio
---

Identify the core insight or solution (the "knot") first, then structure the narrative as: problem (snarl) → approach (pulling) → outcome (tied knot) → margin note (the human lesson). The knot can be literal (a bowline for "built from nothing") or metaphorical (a reef knot for "legacy code needs retying"). It gives readers a shape to remember.

When writing about real companies, research public information before drafting. Keep confidential details vague—use "a startup selling eSIMs" instead of naming a hidden client, "Novira's partners" instead of listing specific customers. Readers trust stories more when they can verify the public facts.
