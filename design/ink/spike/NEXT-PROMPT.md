# Continue: portfolio story page, fix pass

## Context
Portfolio for Pawel Komorkiewicz, a front end developer. It is a single hand-drawn "ink" page.
- Page: `portfolio/design/ink/spike/index.html`. The previous version is backed up as `index.v1.html`.
- Styles: `spike/ink.css` is the base ink system (masks, the boil filter, paper, theme). `spike/story.css` is the story layer.
- Assets: `design/ink/svg/*.svg` (ink drawings, `fill="currentColor"`, painted through the `.ink` mask with `--src`/`--ar`), `design/ink/pencil/*.webp` (arrow, circle, strike, tick, underline, scribble), `design/ink/paper/` (includes `paper-night.png` and `grain-tile.png`).
- Art pipeline: `gen-batch*.sh` (image generation through `agy`), then `vectorize.sh raw/<in>.jpg <name>` to get an SVG.
- Serve with `cd portfolio/design/ink && python3 -m http.server 8765`, then open `http://localhost:8765/spike/index.html`.
- Story, top to bottom: hero "A conversation between code and people." → `.magic` kite lift (tall section, sticky `.pin`, frames stepped by the `--lift` view timeline) → `.care` "What I hold on to" → `.line` CV sheet (`.sheet`: SVG `.string` drawn on scroll, `.entry` knots, pencil `.m` marks, margin notes) → `.next` night / small planet (inline SVG: `.stars`, `.cam` pull-back on the `--next` timeline) → `.work` P.S. app shelf → `.contact`.
- Rule: the resting state is the finished drawing. Scroll-driven animations only add the way there, inside `@media (prefers-reduced-motion: no-preference)` and `@supports ((animation-timeline: view()) and (animation-range: entry))`. Put `animation-timeline` after the `animation` shorthand. No scroll-timeline polyfill.

## Done (2026-09-28 fix pass)
- Root cause of both big gaps: `body { overflow-x: hidden }` with `html { overflow-x: clip }` made body a scroll container, so sticky never stuck and every view timeline was inactive (final frames only). Now `overflow-x: clip` on body (ink.css). Never use `hidden` there.
- `.magic`: pin sized to content (`--pin-h: min(100vh, 11.5rem + 34vw, 34rem)`, measured), centred with `top`, section height `--pin-h + --steps`; frames use `cover` length offsets so they run exactly over the sticky window. "there it goes" lands, then the pin releases. Checked 320-1920px.
- CV origin thread removed; knots checked centred on the string.
- Paper/night edge: `spike/wash-top.webp` + `wash-bottom.webp` (~40KB each, alpha-only ink-wash masks, horizontally seamless) from `design/ink/gen-wash.sh`. Used as `mask` on `.next::before` with `--abyss` colour; edges hang outside the section (`--wash`, `--bleed`) so the scene is always full night.
- Night parallax: `.layer.far/.mid/.near` (dust, small sparkles + glow dots, near sparkles) scale/translate by depth on `--next`.
- Stars: `#spark` 4-point sparkle + `#glow-dot` via `<use>` (fill set on the `<use>`: page CSS does not reach use instances). Time-based twinkle with per-star `--tw`/`--tdel`, only under `prefers-reduced-motion: no-preference`. Markup generated by a seeded script (not kept; regenerate if needed).
- `.next` height 215vh, caption lands at 80%, releases right after.
- Verified Chromium 1280/390/reduced, Firefox (static + twinkle), WebKit; no horizontal overflow.
